# Projects

Demo modelling projects created with `latris init`. Each one is a
real git-versioned project you can `cd` into and explore with the CLI or
GUI.

These projects are **local development artifacts** — they are not checked
into git (listed in `.gitignore`). Create your own:

```
latris init my-project --question "Does X cause Y in context Z?"
cd my-project
latris project show
latris node list
latris log
```
